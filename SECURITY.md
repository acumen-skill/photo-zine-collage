# Security Policy

## Supported versions

Until the first tagged release, security fixes are applied to the latest repository state. After releases begin, the newest minor release will receive security fixes.

## Report a vulnerability

Use GitHub private vulnerability reporting for credential exposure, unsafe file handling, dependency vulnerabilities, or privacy problems. Do not open a public issue containing exploit details, credentials, private prompts, or user photographs.

Include the affected script or workflow, the smallest safe reproduction, expected impact, and any suggested mitigation. Replace real photographs and secrets with synthetic fixtures before submitting a report.

This project processes files supplied by the user and calls an available image generation/editing capability. Review the data-handling terms of the selected image tool before using confidential photographs.
